## 今日核心总结：SVI波动率模型完整流程

### 一、SVI 模型本质

**拟合目标**：总隐含方差 \( w(k) = \sigma^2 \times T \)，不是 IV

**公式**：
\[
w(k) = a + b\left(\rho(k-m) + \sqrt{(k-m)^2 + \sigma^2}\right)
\]
- \( k = \ln(K/S) \)：对数行权价
- 参数：\( a \)（水平）、\( b \)（陡峭）、\( \rho \)（偏度）、\( m \)（位置）、\( \sigma \)（平滑）

---

### 二、数据预处理（关键两步）

| 步骤 | 代码 | 注意 |

| 筛选 BTC | `df[df['symbol'].str.startswith('BTC')]` | |

---

### 三、损失函数 = 加权 MSE + 软约束

```python
loss = mean((w_obs - w_pred)² × weight) + penalty
```

**权重（高斯核）**：聚焦 ATM（流动性最好）
```python
weight = exp(-k² / (2σ_k²))
weight /= weight.sum()   # 归一化
```

**软约束惩罚**：
- \( b < 0 \) → 加罚
- \( |\rho| \ge 0.999 \) → 加罚
- \( \sigma \le 0 \) → 加罚

> 硬约束由 `bounds` 处理（如 \( b \ge 0, \sigma \ge 0.001 \)）

---

### 四、优化算法：L-BFGS-B

| 特点 | 说明 |
|------|------|
| 类型 | 拟牛顿法（自动近似海森矩阵） |
| 优势 | 不需要手动调学习率，收敛快 |
| 边界 | 支持参数上下界 |
| 适用 | 小规模参数（5个） |

```python
from scipy.optimize import minimize
result = minimize(loss, x0, method='L-BFGS-B', bounds=bounds)
```

**不需要手动写梯度**：优化器用有限差分自动计算。

---

### 五、参数初始化（物理意义驱动）

| 参数 | 初始化方法 | 物理含义 |
|------|-----------|----------|
| \( a \) | ATM 处的 \( w \) | 最小波动率水平 |
| \( m \) | ATM 处的 \( k \) | 微笑最低点位置 |
| \( b \) | 两端斜率均值 | 整体微笑陡峭程度 |
| \( \rho \) | 左右陡峭度比较（负偏/正偏） | 偏度方向 |
| \( \sigma \) | \( k \) 值跨度 / 4 | 微笑宽度 |

**判断**：\( \rho < 0 \) → 左偏（股票期权，下跌恐慌）；\( \rho > 0 \) → 右偏（商品期权）

---

### 六、拟合目标选择（w vs IV）

| 目标 | 优点 | 缺点 |
|------|------|------|
| **w（总方差）** | 理论正确、无套利 | 短期 IV 误差被放大 |
| **IV（波动率）** | 可视化直观 | 可能违反理论约束 |

**结论**：学术/定价用 `w`，展示用 `IV`

> 你发现“SVI曲线比观测点低”就是因为拟合的是 `w`，短期 `T` 小会放大误差。

### 八、R² 拟合优度计算

```python
w_pred = svi_w(k_obs, params)
ss_res = np.sum((w_obs - w_pred)**2)      # 残差平方和
ss_tot = np.sum((w_obs - w_obs.mean())**2) # 总平方和
r2 = 1 - ss_res / ss_tot
```

- R² 越接近 1 越好
- 负值表示拟合比直接用均值还差
