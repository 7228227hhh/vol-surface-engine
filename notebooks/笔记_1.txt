## 一、多线程基础

### 1. `threading.Thread` 参数

```python
thread = threading.Thread(target=run_loop, daemon=True)
```

| 参数 | 含义 | 说明 |
|------|------|------|
| `target=run_loop` | 线程执行的函数 | 线程启动后自动调用，函数结束线程就结束 |
| `daemon=True` | 守护线程 | 主线程结束时，守护线程自动终止（无论是否执行完） |
| `daemon=False` | 非守护线程（默认） | 主线程会等待所有非守护线程执行完毕才退出 |

**守护线程的特点**：
- ✅ 适合：后台监控、心跳检测、日志记录、缓存清理
- ❌ 不适合：数据写入、交易处理、资源操作（可能被突然终止）

## 二、异步编程核心概念

### 1. 协程（Coroutine）

```python
async def my_func():    # 协程函数
    await asyncio.sleep(1)
    return 42

coro = my_func()        # 协程对象（调用函数得到，不执行）
result = await coro     # 等待协程执行，得到返回值 42
```

| 概念 | 定义 | 示例 |
|------|------|------|
| 协程函数 | 用 `async def` 定义的函数 | `async def foo():` |
| 协程对象 | 调用协程函数返回的对象 | `coro = foo()` |
| `await` | 等待协程执行完成并获取结果 | `result = await coro` |

**关键理解**：
- `await` **不是** `return`，而是等待异步操作完成
- 协程可以在 `await` 处暂停，让出控制权给事件循环

---

### 2. 事件循环（Event Loop）

```python
def run_loop():
    # 1. 创建事件循环
    loop = asyncio.new_event_loop()
    
    # 2. 绑定到当前线程
    asyncio.set_event_loop(loop)
    
    # 3. 运行协程直到完成
    loop.run_until_complete(subscribe_spot_price())
    
    # 4. 清理
    loop.close()
```

**事件循环的作用**：
- 调度和执行协程
- 处理 I/O 事件
- 在等待时切换到其他任务

**重要**：每个线程需要自己独立的事件循环，`set_event_loop()` 会自动绑定到调用它的线程。

---

### 3. `async with` 异步上下文管理器

```python
async with websockets.connect(uri) as ws:
    await ws.send("hello")
# 退出时自动执行 await ws.close()
```

| 对比 | 普通 `with` | `async with` |
|------|-------------|---------------|
| 进入方法 | `__enter__` | `__aenter__` |
| 退出方法 | `__exit__` | `__aexit__` |
| 是否支持 await | ❌ | ✅ |
| 使用位置 | 任何函数 | 只能在 `async def` 内 |

**作用**：自动管理需要异步操作的资源（网络连接、异步文件、数据库连接等）

---

### 4. `async for` 异步迭代

```python
async for message in ws:
    process(message)
```

**为什么不能用普通 `for`？**
- `ws` 是**异步可迭代对象**（实现了 `__aiter__`）
- 每次迭代需要等待网络 I/O

| 对比 | 普通 `for` | `async for` |
|------|------------|--------------|
| 适用对象 | 可迭代对象 | 异步可迭代对象 |
| 迭代过程 | 同步阻塞 | 异步非阻塞 |
| 使用位置 | 任何函数 | 只能在 `async def` 内 |

## 四、生成器与迭代器（完整版）

### 1. 迭代器协议

```python
# 迭代器必须实现两个方法
class MyIterator:
    def __iter__(self):
        return self           # 返回迭代器本身
    
    def __next__(self):
        # 返回下一个值，没有时抛出 StopIteration
        if self.index >= len(self.data):
            raise StopIteration
        value = self.data[self.index]
        self.index += 1
        return value
```

### 2. 可迭代对象 vs 迭代器

| 概念 | 定义 | 是否有 `__iter__` | 是否有 `__next__` |
|------|------|-------------------|-------------------|
| 可迭代对象（Iterable） | 可以被 `iter()` 转换 | ✅ | ❌ |
| 迭代器（Iterator） | 可以逐个产生值 | ✅ | ✅ |

**例子**：
```python
my_list = [1, 2, 3]      # 可迭代对象（不是迭代器）
it = iter(my_list)       # 迭代器

for item in my_list:     # for 内部自动调用 iter()
    print(item)
```

### 3. 生成器

**生成器是创建迭代器的简便方式**，使用 `yield` 关键字：

```python
def count_up_to(n):      # 生成器函数
    i = 1
    while i <= n:
        yield i          # 返回 i 并暂停
        i += 1

gen = count_up_to(3)     # 生成器对象
print(next(gen))         # 1
print(next(gen))         # 2
print(next(gen))         # 3
# next(gen)             # StopIteration
```

### 4. 生成器表达式

```python
# 列表推导式（立即生成所有值）
list_comp = [x*2 for x in range(10)]   # 占用内存

# 生成器表达式（惰性求值）
gen_exp = (x*2 for x in range(10))     # 几乎不占内存
```

### 5. 对比总结表

| 特性 | 迭代器 | 生成器 |
|------|--------|--------|
| 实现方式 | 定义类，实现 `__next__` | `yield` 关键字 |
| 代码量 | 较多 | 简洁 |
| 状态维护 | 手动 | 自动（yield 处暂停） |
| 惰性求值 | ✅ | ✅ |
| 可迭代次数 | 一次 | 一次 |
| `send()`/`throw()` | 需手动实现 | ✅ 内置支持 |

### 6. 异步生成器（与你代码相关）

```python
async def async_generator():
    for i in range(3):
        await asyncio.sleep(1)
        yield i        # 异步产生值

async for value in async_generator():
    print(value)       # 每秒输出一个数
```

**你的 WebSocket 代码本质类似**：
```python
async for message in ws:   # ws 是异步可迭代对象
    process(message)       # 每次等待新消息到来
```

## 五、常见问题与陷阱

### 1. 协程对象不等于协程函数
```python
async def foo():           # 协程函数
    return 42

print(type(foo))           # <class 'function'>
print(type(foo()))         # <class 'coroutine'>
```

### 2. 生成器/迭代器只能使用一次
```python
gen = (x for x in range(3))
print(list(gen))  # [0, 1, 2]
print(list(gen))  # []  已耗尽！
```

### 3. `await` 必须在 `async def` 中使用
```python
def wrong():               # ❌ 普通函数
    await asyncio.sleep(1) # SyntaxError

async def correct():       # ✅ 异步函数
    await asyncio.sleep(1)
```

### 4. 线程中的事件循环要单独设置
```python
# ❌ 错误：在主线程设置，在其他线程使用
loop = asyncio.new_event_loop()
asyncio.set_event_loop(loop)

def run_in_thread():
    loop.run_until_complete(...)  # 跨线程不安全

# ✅ 正确：在每个线程中分别设置
def run_in_thread():
    loop = asyncio.new_event_loop()
    asyncio.set_event_loop(loop)
    loop.run_until_complete(...)
```

## 六、代码设计模式

### 1. 带重启机制的线程事件循环

```python
def run_loop():
    while True:  # 无限重启
        try:
            loop = asyncio.new_event_loop()
            asyncio.set_event_loop(loop)
            loop.run_until_complete(subscribe_spot_price())
        except Exception as e:
            print(f"错误: {e}，重启中...")
            time.sleep(1)
        except KeyboardInterrupt:
            print("收到中断信号")
            break
        finally:
            loop.close()
```

### 2. 守护线程启动异步任务

```python
def start_websocket_thread():
    thread = threading.Thread(target=run_loop, daemon=True)
    thread.start()
    return thread
```

## 九、关键要点

1. **协程不是线程**：协程在单线程内并发，线程是并行（多核）
2. **`await` 不等于 `return`**：`await` 等待异步操作，`return` 返回值并结束函数
3. **每个线程有自己的事件循环**：不能跨线程使用
4. **生成器是特殊的迭代器**：使用 `yield` 更简洁
5. **`async for` 用于异步可迭代对象**：每次迭代可能需要等待 I/O
6. **守护线程会被强制终止**：不要用于关键事务
7. **重启机制保护事件循环**：用 `while True` 包裹，异常后重试
